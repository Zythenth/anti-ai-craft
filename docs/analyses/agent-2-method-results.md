# Agent 2 results — teaching method

## Scope examined

The agent analyzed how the external collection teaches, routes, and applies its
principles, including the primary document, thematic chapters, supporting
instructions, maintenance scripts, and update conventions.

## Useful teaching patterns

- begin with a recognizable problem, not an indiscriminate list;
- provide an operational action after the explanation;
- keep thematic chapters short and load them on demand;
- allow consultation by unit without requiring linear reading;
- use evidence to turn abstract advice into a verifiable decision.

## Limitations found

- the format did not consistently state when a recommendation should be rejected;
- normative force, convention, and opinion appeared too close together;
- the presence of a source could be mistaken for evidence of local applicability;
- the update process was larger than necessary for a local skill;
- the design material contained no TDD requirement, so such an obligation should
  not be invented during integration;
- automating copying or updates would create unnecessary dependency and risk.

## Improved method incorporated

The new method begins with the task, audience, stage, surface, and decision. It
then:

1. separates the person's outcome from the organization's outcome;
2. selects only the relevant chapter;
3. chooses no more than three applicable IDs;
4. translates each ID into observable content, hierarchy, interaction, or state;
5. defines an indicator, guardrail metrics, disconfirming evidence, and reversal;
6. checks autonomy, accessibility, privacy, and security;
7. implements only when authorized.

This method also defines the order of authority among standards, the project
contract, the user's decision, evidence, guidance, heuristics, and preferences. An
external recommendation is treated as a hypothesis until the real context
supports it.

## Coverage produced by the agent

- `ADO-001` through `ADO-010`: context and strategy;
- `ADO-011` through `ADO-020`: positioning and promise.

During final consolidation, semantically related principles were rewritten to
cover fact versus hypothesis, the chain from action to value, out-of-scope work,
category, value mechanism, message order, vocabulary, evidence, eligibility, and
cross-channel consistency.
